## Brand communication

Mega Campaign ผ่านการเนรมิต Live Event สังเวียนมวยสุดยิ่งใหญ่ "GRABFOOD MEGA SALE ศึกดวล HOT DEALS" ที่ดึงพลังกระแสแฟนดอมและไลน์อัป KOLs พร้อมศิลปินระดับท็อปมาร่วมสร้าง Talk of the Town การผสานความบันเทิงเข้ากับโปรโมชันส่งเสริมการขายอย่างลงตัว ส่งผลให้แคมเปญเกิดกระแสไวรัลถล่มทลาย จนทะยานขึ้นติดเทรนด์อันดับ 1 บนแพลตฟอร์ม X ด้วยยอด Retweets มากกว่า 600,000 ครั้ง

## Approach

- **Solution:** Brand Communication / Live Event / KOL
- **Mechanic:** Mega Campaign / Live Event / KOL
- **Typical fit:** 3–6 months / 800K+
- **Matching keywords:** food delivery, mega campaign, live event, KOL, awareness, sales
